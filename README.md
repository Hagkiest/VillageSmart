# 农村村务管理系统 — CountryManageSystem

## 项目简介

农村村务管理系统是一套面向基层村务管理的综合信息化平台，集成了居民信息管理、人口统计、补贴发放、党建工作、项目管理、调解仲裁、数据安全等核心功能，旨在提升村务治理效率与信息化水平。

### 核心功能

| 模块 | 功能 |
|------|------|
| 居民管理 | 居民信息录入、查询、导入导出（Excel）、批量删除 |
| 人口统计 | 年龄结构、性别分布、村组统计、人口趋势 |
| 社会救助 | 低保管理、残疾人管理、补贴发放 |
| 党建管理 | 党员管理、组织架构、党务记录 |
| 乡村振兴 | 项目管理、耕地管理、公益岗位 |
| 调解仲裁 | 调解档案、纠纷趋势 |
| 数据安全 | 数据库备份/恢复、操作日志、清除数据 |

### 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | React 19 + TypeScript |
| 构建工具 | Vite 6 |
| UI 组件 | shadcn/ui (Radix UI) |
| 样式 | Tailwind CSS |
| 后端框架 | Django 6.0 |
| 数据库 | MySQL 8+ / SQLite |
| 打包 | Nuitka 4 + Zig (可选) |

### 模块说明

- **`village_affairs/`** — Django 主应用，包含全部后端 API 和业务逻辑
- **`config/`** — Django 项目配置（数据库连接、中间件注册、应用安装）
- **`管理系统界面设计/`** — React 前端源码，使用 Vite 构建，输出到 `village_affairs/static/frontend/`
- **`media/`** — 用户上传文件（运行时自动创建）
